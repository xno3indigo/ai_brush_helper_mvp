# Prompt：根据映射 Spec 生成 PPT 渲染代码

你正在根据人工审查过的 PPT-DB 映射 spec 生成 Python 渲染适配代码。

不要生成问卷清洗代码，不要生成 DP 指标计算代码，不要写数据库。你的职责是把已经存在的 DP 结果表和配置表渲染到 PPT 模板中。

## 输入材料

你会收到：

1. 已审查的 `mapping_spec.generated.yaml`。
2. PPT 模板路径。
3. DB 导出目录，包含：
   - `bh_database_table`
   - `bh_database_table_field`
   - `bh_charts_replaces`
   - 已导入数据库的 DP 结果表导出
4. 目标项目里已有的 PPT 渲染器或工具函数示例。

## 硬性规则

- 不得写死数据库账号密码。
- 默认使用 DB 导出文件进行 dry-run。
- 如果需要接真实数据库，必须通过外部配置读取连接信息。
- 不得修改上游 DP 结果表。
- 生成文件必须带这个头部注释：
  `# Generated by ai_brush_helper; review before production use.`
- 所有映射缺口必须 fail fast，不允许静默跳过。

## 必须实现的行为

渲染代码应该：

- 读取 `mapping_spec.generated.yaml`。
- 读取 DB 导出的 config 和结果表。
- 用 `text_bindings` 替换 PPT 中的 `${VIEW...}`。
- 用 `chart_bindings` 找到对应页面和图表序号，刷新图表数据。
- 输出新的成品 PPT 文件。

## 必须包含的校验

包含 validation 函数，用来检查：

- spec 中的结果表不存在。
- spec 中的字段不存在。
- PPT 中有未被替换的 `${...}`。
- 图表序号超过该页真实图表数量。
- 渲染后 PPT 仍然有残留占位符。
